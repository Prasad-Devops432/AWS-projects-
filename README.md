# 🚀 AWS Projects – DevOps & Cloud Engineering Portfolio

A collection of hands‑on **AWS, DevOps, CI/CD, Monitoring, Auto‑Scaling, Docker, and Jenkins** projects designed to demonstrate real‑world cloud engineering skills.  
This repository includes multiple end‑to‑end implementations using AWS services, automation tools, and application deployments.

---

## 📁 Repository Structure

### **1. Maven Application (Java)**
A Java‑based Maven application configured with:
- `pom.xml` containing project metadata  
- Build configuration for packaging  
- Ready for CI/CD integration with Jenkins or AWS CodePipeline  

**Skills:** Maven, Java, Build Automation, CI/CD

---

### **2. Node.js Application**
A lightweight Node.js server application:
- Contains `server.js`  
- Can be containerized using Docker  
- Suitable for deployment on EC2, ECS, or Kubernetes  

**Skills:** Node.js, Express, Docker, AWS Deployment

---

### **3. Auto‑Scaling Project**
An AWS Auto Scaling demonstration:
- EC2 Auto Scaling Group (ASG)  
- Launch Templates  
- Load Balancer integration  
- Scaling policies based on CPU or custom CloudWatch metrics  

**Skills:** EC2, ASG, ALB, CloudWatch, High Availability

---

### **4. CloudWatch Monitoring Project**
A monitoring and alerting setup using:
- CloudWatch Metrics  
- CloudWatch Alarms  
- Log Groups & Log Streams  
- Dashboards for visibility  

**Skills:** Monitoring, Logging, Alerting, Observability

---

### **5. Jenkins CI/CD Project**
A complete Jenkins pipeline setup:
- Jenkinsfile for automated builds  
- Integration with GitHub  
- Build → Test → Package workflow  
- Docker integration for container builds  

**Skills:** Jenkins, Pipelines, CI/CD, Docker

---

### **6. Dockerized Applications**
Multiple applications containerized using Docker:
- Dockerfile included  
- Supports local builds and cloud deployments  
- Can be extended to ECS, EKS, or Kubernetes  

**Skills:** Docker, Containerization, DevOps
